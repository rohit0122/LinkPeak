2. Technical Stack
Framework: Next.js 16.0.0 (App Router)

Styling: Tailwind CSS 4.0 + DaisyUI 5.0 (Latest)

Icons: react-icons exclusively

Database: MongoDB Atlas (Mongoose Singleton)

Auth: In-House JWT (jose) + HttpOnly Cookies

Email: Nodemailer with custom HTML templates

Analytics: Recharts for graphical data

QR Engine: qrcode.react with PNG export

Build Target: Optimized for Vercel

4. In-House Auth & User Lifecycle
Verification: Signup -> isVerified: false -> Nodemailer link -> isVerified: true.

Security: JWT session management + HttpOnly cookies.

Profile: Centralized screen to update Name, Password, and Profile Picture.

Proxy Guard: proxy.js middleware validates roles and verification status.

5. The "Live Tracking" & Engagement Engine
Interaction Logging: Atomic $inc for Views and Clicks.

Fan Love (Likes): Framer Motion heart button with optimistic UI.

QR Bridge: Custom QR codes with logo support and high-res PNG download.

6. Template Engine & Previewer
The 5 Designs: Classic, Grid, Hero, Social Minimal, and Modern Card.

Live Preview: DaisyUI mockup-phone in dashboard for real-time theme/template editing.

7. Analytics & Reporting
Counters: Live Total Views, Clicks, and Likes on Dashboard.

Graphs: Tiered Recharts data (7-day/90-day/Lifetime).

8. Support & Retention Automation
Ticketing: User creation with file upload -> Admin global helpdesk.

Retention: Dashboard banner + Cron Job emails (7, 3, 1 day before expiry).

9. Layout Strategy
Marketing/App Layout: Sticky Glassmorphism Header + Multi-column Footer.

Public Bio Page (/[slug]): No Global Header/Footer. Clean environment.
