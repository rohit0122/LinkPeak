To ensure your AI agent (like Cursor, Windsurf, or a custom GPT) processes this complex build without crashing, hallucinating, or breaking functionality, you must use a Modular "Layered" Implementation strategy.

Never give the entire 3,000-line requirement to an agent in one go. Instead, feed it the README.md you just created as its "Constitution," and then issue Sprints.

Step 1: The "Constitutional" Initial Prompt
First, upload your README.md and say this:

"I am building LinkPeak. Attached is the Master Specification. Read this carefully but do not write any code yet. Acknowledge that you understand the Tech Stack (Next.js 16, Tailwind 4, DaisyUI 5), the Global Config system, and the Custom Auth logic. We will build this in 5 distinct phases."

Step 2: The Sprint Strategy (Issue these one by one)
Sprint 1: The Foundation (Structure & Config)
Goal: Establish the bones and branding.

Prompt: "Let's begin Sprint 1. Create the constants/config.js with the site name and limits. Set up the Vercel-optimized Mongoose singleton in lib/db.js and the lib/env-check.js utility. Ensure next.config.js is set up for image remote patterns. Verify the folder structure matches the README."

Sprint 2: Security & Auth (The Engine)
Goal: Login, Register, and Verification.

Prompt: "Sprint 2. Implement the custom JWT Auth using jose. Create the app/(auth) routes and the lib/mailer.js for Nodemailer. Then, implement the proxy.js middleware to gate the /dashboard and /admin routes. Users must be verified to log in."

Sprint 3: Dashboard & Link Management (The Core)
Goal: Dynamic CRUD and Previewer.

Prompt: "Sprint 3. Build the Dashboard UI using DaisyUI. Create the Link Editor with drag-and-drop. Integrate the PreviewPhone.jsx component that reflects the 5 templates and 30+ themes in real-time. Use an Axios interceptor for a global loading overlay during all saves."

Sprint 4: Tracking & Engagement (The USP)
Goal: Live analytics and Like button.

Prompt: "Sprint 4. Implement the Live Tracking system. Add the POST /api/track/view and POST /api/track/click endpoints with atomic increments. Build the 'Fan Love' Like button with Framer Motion. Create the Analytics tab using Recharts based on the user's plan tier."

Sprint 5: QR, Support & Vercel Cleanup
Goal: Completion and Deployment.

Prompt: "Final Sprint. Add the QR code generator with PNG download. Build the Support Ticket system and the Vercel Cron Job for expiry emails. Finally, run npm run build and fix any linting or type errors to ensure a clean Vercel deployment."

3 Rules to Prevent AI Overload
"Stop and Verify": After every Sprint, ask the AI: "Does this current code strictly follow the naming conventions and global constants in constants/config.js?"

"Atomic Files": If a file becomes too large (like the Link Editor), tell the AI: "Refactor the Link Editor into smaller sub-components inside components/dashboard/ to maintain clean code."

"Memory Reset": Every few hours, start a new chat session but re-paste the README.md so the AI doesn't lose the "Global Identity" and starts hardcoding names.
